Приложение Заметки

Описание
Практическая работа по разработке Android-приложения. Реализована навигация между тремя экранами (MainActivity, EditActivity, ViewActivity) с использованием явных Intent. Данные хранятся в оперативной памяти (MutableList), списки отрисовываются через LayoutInflater.
